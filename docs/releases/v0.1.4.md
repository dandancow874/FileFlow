修复文件夹大小排序、Eagle 复制和大小写重命名，增加 Listary Quick Switch 接入，并调整窗口化时的标题栏布局。

## 下载

解压 `FileFlow-v0.1.4-win64.zip`，运行其中的 `FileFlow\FileFlow.exe`。支持 Windows 10/11 64 位，VC 运行库随包附带；SHA256 校验文件一同提供。

## 更新

- 文件夹大小排序改用大小列显示的内容总大小，按字节数比较。计算完成自动重排；未完成项在各自分组末尾等待。保留文件夹/文件优先选项。
- 按大小排序时，后台计算全部筛选结果中的文件夹，包括未滚动到的项。请求入队去重，队列满后可重试，避免重绘反复扫描。
- 修复窗口变窄或双栏标签过多时关闭按钮被挤出边界的问题。最小化、最大化、关闭固定在最右侧，“＋”紧跟最后一个标签。
- 支持仅修改文件/文件夹名称大小写，如 `poe → POE`；批量重命名与 Ctrl+Z 恢复原大小写也适用，其他同名项目仍受保护。
- 修复 Eagle Ctrl+C 后到 FileFlow Ctrl+V 的 `0x80070057` 错误，统一混用的路径分隔符，并保留 UTF-16 文件名称。
- 增加 Listary 6 插件与当前目录查询接口，按 FileFlow 当前活动栏/标签向 Listary 提供路径，支持文件选择窗口的 Quick Switch 自动跟随。

## Listary 插件

包内 `integrations\listary` 包含插件、源码、安装脚本和说明。需要已安装 Listary 6 与 .NET Framework 4.8；FileFlow 主程序本身不需要 .NET。

安装插件到 Listary 的 Program Files 目录需要 Windows 管理员授权。安装脚本备份并保留其他配置，关闭插件在 FileFlow 内的键入搜索、双击和中键接管。安装后请以普通权限运行 Listary。升级 Listary 后如果插件目录被移除，可重新安装。
