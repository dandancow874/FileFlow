本次更新增加原生视频预览、同名文件处理及覆盖撤销，并改善文件夹封面、磁盘信息和程序图标。

## 下载

解压 `FileFlow-v0.1.3-win64.zip`，进入 `FileFlow` 文件夹，运行 `FileFlow.exe`。支持 Windows 10/11 64 位，VC 运行库随包附带。SHA256 校验文件与压缩包一同提供。

## 更新

- Space 视频预览使用 Windows Media Foundation，支持播放/暂停、拖动进度和静音；支持的格式取决于系统解码器。
- 复制、剪切粘贴、应用内拖放及双栏传输遇到同名目标时，提供覆盖、重命名、取消选项。同目录复制继续自动生成副本。
- Ctrl+Z 支持撤销覆盖复制与覆盖移动，恢复原目标内容；文件夹覆盖按整个文件夹替换处理。
- 覆盖备份移入 `%LOCALAPPDATA%\FileFlowEgui\overwrite-backups`，不再出现在工作目录；自动迁移访问目录中的旧版备份，清理空备份并保留非空内容。撤销记录仍仅限当前运行会话。
- 中、大、超大图标视图显示文件夹内部第一张图片的缩略图。
- 此电脑显示磁盘总容量、可用空间及用量；包括移动盘在内的磁盘根目录可返回此电脑。
- EXE 按实际文件读取各自图标，避免同扩展名程序共用图标。
- 改善拖出文件时按 Alt+Tab 切换应用的拖放交接。

## 验证

- 编译与 Clippy 检查通过；常规自动测试 37 项通过、3 项按需集成测试默认跳过。
- 另行执行并通过原生视频播放/暂停/跳转/释放文件测试，以及跨磁盘文件夹覆盖备份与撤销测试。
