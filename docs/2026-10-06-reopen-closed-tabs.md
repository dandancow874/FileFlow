# 2026-10-06 恢复关闭的标签页

- 新增 `ReopenClosedTab` 动作，默认 `Ctrl+Shift+T`，也出现在快捷键设置页；新建标签继续使用 `Ctrl+T`。
- 鼠标关闭和 `Ctrl+W` 共用关闭入口，记录路径、原栏和索引。左右栏共用最多 32 条关闭记录，按最近关闭的顺序恢复，每次恢复一条并激活；仅当前运行有效，无记录时不新增标签。
- 恢复右栏标签时直接启用双栏，避免普通双栏切换覆盖右栏目录。最后一个标签不允许关闭，也不加入恢复记录。
- 修正关闭活动标签前方的非活动标签时索引未减一的问题，保持当前目录；恢复时原索引超出当前标签数则插入末尾。
- 自动验证通过：`cargo check --bins`、`cargo test --all-targets`（21 通过，1 个真实剪贴板测试跳过）、`cargo clippy --all-targets -- -D warnings`、`cargo build --release --bins`。
- 实际窗口验证通过：左栏测试目录用 `Ctrl+W` 关闭后，`Ctrl+Shift+T` 恢复原目录、原位置并激活；右栏创建临时标签、关闭后隐藏双栏，恢复快捷键重新显示右栏并恢复其目录；关闭记录耗尽后再次按快捷键，标签数不变。验证后关闭临时右栏标签并返回原左栏工作目录。
- 已更新 `target/release/fileflow.exe`，运行日志含 `reopen-tab-v1` 标记。
